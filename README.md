on the occasion of Daniel R W's 7th birthday, on July 27th, 2026, I created this videogame.

text adventure portion created with Twine 2.11.1 https://twinery.org/

... and Harlowe 3.3.9 https://twine2.neocities.org/

boss battle portion created with Phaser 3 https://phaser.io/

I relied heavily on the following pokemonlike Phaser 3 tutorial by Scott Westover https://www.youtube.com/playlist?list=PLmcXe0-sfoSgq-pyXrFx0GZjHbvoVUW8t

font used: VT323 https://fonts.google.com/specimen/VT323

many sound effects are from https://www.bfxr.net/

a playlist of some of the music used https://open.spotify.com/playlist/5WVhALCwR8GktHSU6XU5xZ?si=0a77d50b88d84b15

a lot of music was made in garageband with midis from musescore

text generator which helped me organize attack animation code https://edukits.co/text-art/

thanks to Angie, Morgan, and Elo for playtesting!
